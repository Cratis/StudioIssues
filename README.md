## About this repository

This repository is the **public issue tracker and feedback channel** for [Cratis Studio](https://cratis.studio).

> **There is no code here.** Studio development happens in a private repository. This repository exists so anyone can report bugs, request features, and discuss ideas with the Cratis team and community.

Use this space to:

- **Report bugs** you encounter while using Studio
- **Request features** or improvements you'd like to see
- **Discuss ideas** with the Cratis team and community

---

## What is Cratis Studio?

[Cratis Studio](https://cratis.studio) is the collaborative environment for designing, visualizing, and editing [Screenplay](https://github.com/Cratis/Screenplay) event models. It is part of the model-first layer of [Cratis](https://www.cratis.io) — alongside Screenplay, [Stage](https://github.com/Cratis/Stage), [Scene](https://github.com/Cratis/Scene), and [Prologue](https://github.com/Cratis/Prologue) — which builds on [Chronicle](https://github.com/Cratis/Chronicle), the Cratis event-sourcing database and runtime, and the [Arc](https://github.com/Cratis/Arc) CQRS framework.

> **Experimental** — Studio and the Cratis model-first layer are experimental and in early development. Expect rough edges and rapid change; that is exactly why your feedback here matters.

Visit **[cratis.studio](https://cratis.studio)** to learn more.

## Reporting issues

When reporting a bug, please include as much of the following as possible:

- A clear and descriptive title
- Steps to reproduce the issue
- What you expected to happen
- What actually happened
- Your Studio version and browser/OS details
- Any relevant screenshots or error messages

[Open a bug report](https://github.com/Cratis/StudioIssues/issues/new?labels=bug)

## Requesting features

Have an idea that would make Studio better? We'd love to hear it!

When requesting a feature, please describe:

- The problem you're trying to solve
